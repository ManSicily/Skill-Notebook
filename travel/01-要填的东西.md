# 要填的东西

把下面填了，跟 `02-交给 agent 的指令.md` 一起发给你的 AI。

**填不出来的先空着** —— 标了「必填」的必须填，其他的 AI 会问你或者替你想。

## A. 基本信息（必填）

```
去哪：       （大概就行，比如「成都周边」或者「北京 → 西安」）
几天：       （比如 5 天）
几个人：     （比如 2 个人）
什么时候走： （有具体日期就写，没有就写「还没定」）
```

**怎么出发**（勾一个）：
- [ ] 自驾
- [ ] 高铁 / 火车
- [ ] 飞机
- [ ] 到了当地再租车 / 打车
- [ ] 还没想好，让它给建议

## B. 要什么功能

下面这些是「行程应用」该有的。**没想法就别动，默认按推荐来**。

### 必须有（建议都留着）

- [x] **行程页** —— 按天列出要去哪、几点、干什么，能加能删能改
- [x] **记账** —— 谁付的钱、几个人分摊，最后算清谁该转给谁
- [x] **离线能用** —— 高速上没信号、山里没网，照样能看行程
- [x] **装到手机桌面** —— 打开就像 App，不用每次输网址
- [x] **备份 / 恢复** —— 一键导出，换手机不丢

### 看你要不要

- [ ] **住宿页** —— 每天住哪、订没订、多少钱一晚
- [ ] **交通页** —— 每段路怎么走、多远、什么时候出发
- [ ] **打卡** —— 每个地点传照片 + 写游记，同行的人都能加
- [ ] **一键导航** —— 点一下直接打开手机上的地图 App
- [ ] **打包清单** —— 出发前要带什么，同行的人勾选互通
      <br>（**两个层级都要能改**：分组像「药品」「数码」，分组里的具体东西像「晕车药」「充电宝」。
      你自己要能随时新建分组、改分组名、调分组的先后顺序；分组里的东西也要能加、能改、能删。
      比如你想加一个「洗漱用品」组 —— 这种东西 AI 是猜不到的，得你自己能建。）
- [ ] **天气** —— 每天目的地的天气
- [ ] **待办提醒** —— 比如「提前 5 天抢票」

### 要不要多人协同

- [ ] **要** —— 同行的人也能编辑同一份行程（需要登录，一人一个账号）
- [ ] **不要** —— 就我自己用，数据只在这台手机上

> 选「要」的话，AI 需要先帮你开一个云服务（免费额度够用），并且会给你一个**邀请码**发给同行的人。
